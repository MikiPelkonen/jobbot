# Resume / CV documents

Drop your resume files in this folder. Supported formats: `.txt`, `.md`, `.pdf`

All files here are gitignored (except this example) so your personal documents are never pushed.

The app reads every file in this folder and passes the content to Claude as supplementary
context when generating cover letters. You can include:

- Your full CV
- Certificates of employment
- Reference letters
- Project descriptions
- Anything else that gives context about your work history

The more detail here, the more specific and accurate the generated letters will be.
